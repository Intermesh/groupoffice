# Security Policy

## Supported Versions

Use this section to tell people about which versions of your project are
currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| >6.8.x  | :white_check_mark: |

### Testing release

Please don't report security issues with our testing release (currently 26.1.x) if they have been fixed in our master branch. These fixes will be merged before it becomes stable.

## Reporting a Vulnerability

If you find a vulnerability in this project, please submit it via GitHub (https://github.com/Intermesh/groupoffice/security) or send it to support@intermesh.nl so we can resolve the issue.
